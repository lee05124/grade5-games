# 五年級湊湊樂

國小五年級益智遊戲，打開網頁就能玩，不需要登入。

- 數字湊湊樂：用加減乘除湊出目標數字（含分數）
- 國字拼拼樂：用兩個部件拼出國字（200 字）
- 成語補補樂：依照意思補完成語（100 個）
- 配合題：成語配意思、部件配國字、算式配答案

整個遊戲只有 `index.html` 一個檔案。要修改題庫，編輯檔案裡的 `CHARS`（國字）和 `IDIOMS`（成語）兩個清單即可。

## 國語課文複習

- `chinese-lesson7.html`：第七課〈為生命找出口〉闖關複習（字音、字形、語詞連連看、課文理解、錯題本）。題庫在檔案裡的 `SOUND`、`SHAPE`、`VOCAB`、`TEXT` 四個清單。

## 國字消消樂

- `hanzi-match.html`：國字三消遊戲，7×7 盤面、每局 20 步，四種模式：偏旁消消、同音消消、同字消消（形近字）、組詞消消。
- 字庫在檔案裡的 `RADICALS`、`SOUNDS`、`SIMILAR`、`WORD_SETS` 四個清單；遊戲首頁的「字庫一覽」可以看到全部的字。

## 腦筋急轉彎擂台

- `brain-teasers.html`：80 題（國字字謎 29、邏輯陷阱 25、數學陷阱 26），分 ★ 到 ★★★ 三種難度。
- 兩種玩法：「自己挑戰」10 題選擇題；「全家搶答」一台手機當主持人，2 到 4 人，可設 30 或 60 秒倒數。
- 會優先出還沒出過的題目。題庫在檔案裡的 `RAW` 清單，遊戲首頁的「題庫一覽」可以看全部答案。

## 長母音消消樂

- `english-long-vowels.html`：英文長母音三消，6×6 盤面、每局 20 步。三種模式：同音消消（長音 a/e/i/o/u）、拼法消消（a_e、ai、ay 等 15 種拼法）、單字消消。
- 120 個單字都是拼法規則、念長母音的字，點單字會用瀏覽器內建語音唸出來。單字表在檔案裡的 `PATTERNS` 清單。

## 圖形實驗室

- `math-shapes.html`：五年級數學圖形單元。
- 線對稱（S-5-4）：8×8 方格，直、橫、斜三種對稱軸，塗出另一半，有提示與檢查。
- 正方體展開圖（S-5-5、S-5-6）：判斷能不能摺成正方體、找出某一面的對面，答完播放 3D 摺疊動畫。能不能摺由程式「滾正方體」判斷，已驗證 34 種六格骨牌中剛好 11 種有效。
